# CATcher art

Draw each cat in each mood and save it here as a PNG named
`<cat id>-<mood>.png`. The moods are `sleepy`, `calm` and `angry`.

| Cat | Sleepy | Calm | Angry |
| --- | --- | --- | --- |
| El Gato (common) | `elgato-sleepy.png` | `elgato-calm.png` | `elgato-angry.png` |
| Know-It-All Nerd Cat (common) | `nerd-sleepy.png` | `nerd-calm.png` | `nerd-angry.png` |
| 1000 Stare Cat (rare) | `stare-sleepy.png` | `stare-calm.png` | `stare-angry.png` |
| Clapping Hand Cat (rare) | `clapping-sleepy.png` | `clapping-calm.png` | `clapping-angry.png` |
| Thinker Cat (legendary) | `thinker-sleepy.png` | `thinker-calm.png` | `thinker-angry.png` |
| Full of Soup Cat (legendary) | `soup-sleepy.png` | `soup-calm.png` | `soup-angry.png` |
| Cat with White Soup on Face (mythical) | `soupface-sleepy.png` | `soupface-calm.png` | `soupface-angry.png` |

You don't need all 21 at once. If a mood drawing is missing, the bot uses
the plain `<cat id>.png` (like `elgato.png`) instead, and a cat with no
picture at all shows its emoji. So you can start with one drawing per cat
and add moods later.

Square images around 512 x 512 look best in Discord. File names must be
all lowercase.
